# Обновление и откат

Для первой установки нужен **`Setup.cmd`**. Для обновления существующего комплекта используйте **`Update.cmd`** из нового архива. Удалять расширение из Chrome не нужно.

## Обновить

1. Скачайте следующий выпуск из [GitHub Releases](https://github.com/zatylok007-web/youtube-downloader-chrome/releases) и распакуйте его **в отдельную папку вне установленного комплекта**. Не распаковывайте поверх старой установки.
2. Дождитесь окончания всей очереди. Ненужные задачи можно отменить отдельно. Затем временно выключите расширение в `chrome://extensions`; Chrome закрывать не нужно.
3. Запустите **`Update.cmd` из новой распаковки**. Установленная папка определяется по регистрации Native Messaging.
4. Скрипт проверит файлы, ID и очередь, создаст резервную копию старой версии в `.updates` и заменит программные файлы. Работающий загрузчик автоматически не останавливается: при занятых файлах обновление откажется продолжать.
5. Дождитесь **`UPDATE OK`**. Установленная папка остаётся прежней; временную новую распаковку после успешной проверки можно удалить.
6. Включите **прежнюю карточку** расширения, нажмите круглую стрелку обновления и проверьте версию. Обновите страницы YouTube.

Настройки, папка загрузок, история, сохранённая очередь, данные Chrome, Native Messaging и готовые MP4 сохраняются. Обновление при активной очереди запрещено. Не меняйте `manifest.json`, публичный ключ и `config\identity.json`: от них зависит идентичность расширения.

После обновления проверьте подключение в меню, выбранную папку, качество и прежние строки списка. Повторный `Setup.cmd` обычно не нужен. Не удаляйте `.updates` до проверки новой версии.

## Вернуть предыдущую версию

1. Завершите очередь и выключите расширение.
2. Запустите **`Rollback.cmd` из установленной папки**.
3. Дождитесь успешного результата, включите и обновите прежнюю карточку в Chrome и страницы YouTube.

Откат возвращает программные файлы из последней резервной копии, сохраняя личные данные. Если файлы вручную изменены или резервная копия повреждена, скрипт остановится с ошибкой вместо перезаписи этих изменений.

## Если обновление прервалось

При обычной ошибке записи уже заменённые файлы автоматически восстанавливаются, а причина ошибки остаётся видимой. Если восстановление тоже не удалось, сохраните полный текст сообщения и всю папку `.updates`.

При отключении питания или принудительном завершении PowerShell автоматическое восстановление не гарантируется. Сначала сохраните всю установленную папку вместе с `.updates`; не запускайте повторное копирование поверх частично изменённой установки. Обратитесь в [Issues](https://github.com/zatylok007-web/youtube-downloader-chrome/issues), проверив сообщение на личные пути.
