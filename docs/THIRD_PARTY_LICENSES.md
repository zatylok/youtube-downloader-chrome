# Компоненты, лицензии и исходные материалы

## Статус публичного распространения

**Релиз v1.1.5 остаётся черновиком. Публичный бинарный архив не распространяется из этого репозитория.**

Версии и контрольные суммы бинарников проверены. Тексты лицензий входят в неизменённый Windows ZIP. Однако полный соответствующий набор исходников и сборочных материалов для включённых GPL-компонентов не подтверждён. Наличие текста лицензии или ссылки только на основной код FFmpeg не закрывает этот вопрос.

Основной блокер — статическая сборка Gyan FFmpeg/FFprobe с внешними библиотеками. У поставщика опубликованы основной FFmpeg commit, конфигурация и версии библиотек; в проверенных release assets 9.0.2 есть бинарные сборки, но полный соответствующий source bundle не найден. Это не утверждение, что поставщик не может его предоставить.

Минимальное условие публичного выпуска: получить и проверить соответствующие исходники необходимых библиотек, применённые изменения и сборочные файлы для **именно этих** бинарников, затем разместить их или обеспечить эквивалентный доступ рядом с бинарной загрузкой. Условия сетевого доступа описаны в [GPLv3, раздел 6(d)](https://raw.githubusercontent.com/FFmpeg/FFmpeg/n9.0.2/COPYING.GPLv3). Обязанность обеспечить доступность остаётся у распространяющего. [Справка FFmpeg](https://ffmpeg.org/legal.html).

Для сторонних компонентов внутри Windows EXE yt-dlp также требуется подтвердить полноту соответствующих исходников. Предложение сопровождающих предоставить исходники сохранено в оригинальных notices; оно не выдаётся здесь за уже выполненную проверку или собственное бессрочное предложение автора проекта. Для необходимых исходных материалов потребуется отдельный проверенный набор или подтверждённый подходящий способ доступа.

Одобренный ZIP не пересобирался, компоненты не подменялись. Полный исходный код оригинального приложения в этот репозиторий не добавлялся.

## FFmpeg: точная сборка

- [Бинарный релиз Gyan 9.0.2](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2), [описание сборок поставщика](https://www.gyan.dev/ffmpeg/builds/).
- [Основной commit FFmpeg 946fcce07b](https://github.com/FFmpeg/FFmpeg/commit/946fcce07b).
- [Вывод `-buildconf` именно комплектного EXE](third-party/FFmpeg-BUILDCONF.txt).
- [README поставщика с конфигурацией и версиями внешних библиотек](third-party/FFmpeg-README.txt).

Это GPLv3-сборка с `--enable-gpl` и `--enable-version3`, включая libx264. Флаг `--enable-nonfree` отсутствует. Сборка не обозначается как LGPL-only. Основной commit и список версий помогают идентифицировать сборку, но не являются полным комплектом corresponding source её внешних библиотек.
