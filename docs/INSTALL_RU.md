# Установка в Windows 11

Готовый комплект поддерживает обычные видео YouTube и Shorts в Google Chrome 120+. Нужна Windows 11 x64. Python, Rust, Node.js и права администратора не требуются. Публичный выпуск 1.1.5 пока ожидает завершения [лицензионной проверки](THIRD_PARTY_LICENSES.md#статус-публичного-распространения).

## Скачать и распаковать

1. После публикации откройте [GitHub Releases](https://github.com/zatylok007-web/youtube-downloader-chrome/releases).
2. В **Assets** выберите `YouTubeShortsDownloader-v1.1.5-Windows.zip` и `YouTubeShortsDownloader-v1.1.5-Windows.zip.sha256`. **Source code (zip)** и **Source code (tar.gz)** для установки не подходят.
3. При необходимости проверьте ZIP в PowerShell: введите `Get-FileHash -Algorithm SHA256 -LiteralPath`, затем в кавычках полный путь к скачанному архиву. Для этой версии ожидается:

   ```text
   1ac5e3252b66efd4cdf302a1e9ba0e98f5e5889e1a9c83d04ca671398a42b846
   ```

4. Полностью распакуйте ZIP средствами Windows. Поместите папку `YouTubeShortsDownloader` в постоянный локальный каталог пользователя, например в «Документы».

Пробелы и кириллица в пути поддерживаются. Не используйте `Program Files`, сетевой диск или OneDrive. Не запускайте файлы внутри архива и не перемещайте установленную папку.

## Подключить расширение

1. Откройте в Chrome `chrome://extensions`.
2. Включите **«Режим разработчика»** справа сверху.
3. Нажмите **«Загрузить распакованное расширение»**.
4. Выберите **`YouTubeShortsDownloader\extension`** из распакованного комплекта.
5. Запустите **`Setup.cmd`** из той же постоянной папки. Дождитесь **«УСТАНОВКА ЗАВЕРШЕНА»**.
6. Обновите карточку расширения круглой стрелкой. Ожидаются версия **1.1.5** и ID **`bkihgeeibbodemeibfdcglojjkiepnlf`**.
7. Откройте меню расширения через значок пазла. Локальный загрузчик должен быть подключён.
8. Откройте или один раз обновите страницу YouTube.

Карточка расширения называется **«Загрузка YouTube Shorts»**; обычные видео также поддерживаются. ID задан существующим публичным ключом и сохраняется при другом пути установки. `Setup.cmd` автоматически регистрирует правильный путь и ID только для текущего пользователя. Повторный запуск из своей папки допустим; чужую установку скрипт не перезаписывает.

**`Check.cmd`** проверяет комплект, компоненты и регистрацию. Реальное соединение с Chrome подтверждается в меню расширения. Запускать `native\shorts-native.exe` вручную не нужно.

## Первая загрузка

На Shorts нажмите стрелку справа от верхнего края плеера. На обычном видео кнопка находится после микрофона возле поиска в верхней панели. В узком окне откройте меню расширения → **«Скачать текущее видео»**.

В **«Настройки и диагностика»** выберите папку и качество: **«Максимальное»**, **«До 1080p»** или **«До 720p»**. По умолчанию используется системная папка **«Загрузки → YouTube Shorts»**. Для вертикального видео предел относится к короткой стороне.

В плавающем списке у каждого видео своя полоса. Дождитесь «Готово» и 100%: файл проверен на наличие видео и звука. Если требуется выбор, нажмите **«Выбрать»** в нужной строке. Совместимые дорожки объединяются без перекодирования; снижение качества или перекодирование требуют решения для этой задачи.

Окно можно перетаскивать за заголовок. **«Отменить»** отменяет только указанную задачу. Маленький **×** скрывает её результат, сохраняя файл и историю. Верхний **×** скрывает окно; новое скачивание открывает сохранённый список.

## Удаление

1. Дождитесь окончания очереди и временно выключите расширение в `chrome://extensions`.
2. Запустите **`Uninstall.cmd`** из установленной папки.
3. В Chrome удалите карточку этого расширения.

Скрипт удаляет только свою регистрацию Native Messaging и созданный `native-host.json`. Скачанные видео, `native\data` с настройками и историей, файлы программы и `.updates` с резервными копиями остаются. После завершения загрузчика их можно сохранить или удалить вручную. Другие расширения, PATH и службы не изменяются.
