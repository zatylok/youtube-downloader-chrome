# Решение проблем

## Кнопка не появилась

Проверьте, что расширение включено, и один раз обновите YouTube после установки или обновления. В настройках проверьте видимость кнопки: например, **«Полупрозрачная»**. На обычном видео стрелка находится после микрофона возле поиска, на Shorts — у верхнего правого края активного плеера. В узкой шапке используйте меню расширения → **«Скачать текущее видео»**.

## Локальный загрузчик не подключён

Полностью распакуйте комплект. Запустите **`Check.cmd`** из установленной папки: он проверяет файлы, компоненты и регистрацию. При отсутствующей регистрации запустите **`Setup.cmd`**, обновите карточку расширения и YouTube. Реальное подключение проверяется в меню расширения. Не запускайте native EXE вручную.

Если Setup сообщает о другой зарегистрированной папке, используйте **`Update.cmd`** для обновления. Для сознательного переноса сначала выполните **`Uninstall.cmd`** в старом месте и сохраните личные данные.

## Setup не находит файлы / неверный ID

Нужен готовый Windows ZIP из **Release Assets**, полностью распакованный. Автоматический **Source code (zip)** содержит документы, а не программу. Загружайте в Chrome папку `extension` из того же комплекта, где лежит `Setup.cmd`.

Ожидаемый ID: **`bkihgeeibbodemeibfdcglojjkiepnlf`**. Он задан публичным ключом и не зависит от папки. Не редактируйте `manifest.json` или `config\identity.json`. Если ID отличается, проверьте выбранную папку и заново распакуйте исходный ZIP.

## YouTube просит подтвердить, что вы человек

Иногда YouTube блокирует анонимную загрузку или ограничивает частоту запросов. Подключение аккаунта, извлечение cookies и автоматический обход проверки не используются. Вход в обычный Chrome не передаёт аккаунт загрузчику. Подождите и попробуйте позже; повторные запросы без паузы не решают такую проверку.

Видео с ограниченным доступом, авторизацией или DRM могут быть недоступны. Наличие Deno/EJS не гарантирует загрузку любого видео.

## Задача ожидает выбора качества

Нажмите **«Выбрать»** в нужной строке. Если исходные дорожки несовместимы с требуемым MP4, сравните доступный вариант без перекодирования и явное разрешение обработки. Изменение относится к этой задаче; глобальная настройка качества сохраняется. Это ожидание решения, а не успешное скачивание.

## Ошибка загрузки или FFmpeg

Проверьте свободное место и доступность выбранной локальной папки. Откройте **«Подробности»** у конкретной задачи и выполните **«Проверить загрузчик»** в настройках. Локальная проверка компонентов не доказывает доступность ролика на YouTube.

В `native\bin` должны находиться `yt-dlp.exe`, `ffmpeg.exe`, `ffprobe.exe` и `deno.exe`. Не заменяйте их случайными файлами. Готовый комплект включает EJS внутри yt-dlp; устанавливать Python или Node.js не нужно. У native-загрузчика и Chrome может отличаться сетевой маршрут; проверьте собственные настройки сети и прокси, не публикуя адреса с паролями.

Журнал конкретной задачи находится в `native\data\diagnostics\ID_ЗАДАЧИ.json`. Он может содержать ID видео и локальные пути. Перед публикацией скопируйте только относящиеся к ошибке очищенные строки; не прикладывайте всю историю, профили, cookies или токены.

## Антивирус или SmartScreen

Личный EXE проекта не подписан коммерческим сертификатом. Не отключайте защиту и не добавляйте всю папку в исключения. Проверьте источник файла, SHA-256 и результат антивирусной проверки. При сомнении остановите установку. Скрипты не отключают защиту и не обходят корпоративные политики.

Для проверки ZIP используйте PowerShell: `Get-FileHash -Algorithm SHA256 -LiteralPath`, затем полный путь в кавычках. Сравните все символы с `.sha256` и суммой в release notes. Это проверяет целостность; доверие к источнику всё равно необходимо.
